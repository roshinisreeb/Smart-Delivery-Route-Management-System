# Smart Delivery Route Management System

A C++ based delivery management system that assigns delivery personnel to orders and calculates the shortest delivery route.

## Features

- Finds the nearest delivery person to a restaurant
- Assigns a delivery person to an order
- Calculates the shortest route from Delivery Boy → Restaurant → User
- Simulates delivery movement
- Displays real-time order status updates
- Uses Dijkstra's algorithm for shortest-path calculation

## Order Status

- Order Preparing
- Order Picked
- Moving to Restaurant
- Heading to User
- Order Delivered Successfully

## Technologies Used

- C++
- STL
- Graph Data Structures
- Dijkstra's Shortest Path Algorithm
- Multithreading
- Chrono
